# Creative Flow — Canvas-first MVP

Single-file HTML prototype for smartphone-first testing.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the root of the repository.
3. Go to Settings → Pages.
4. Select branch `main` and folder `/root`.
5. Open the generated GitHub Pages URL.

## MVP features
- Projects
- Canvas
- Text / quote / link / color / image nodes
- Drag nodes
- Link nodes
- Create clusters
- Lock cluster as Vision
- Make area with passes, review notes and tasks
- LocalStorage persistence
